# 组导入

`selector`、`urltest` 和 `subscription` 均支持 `import`。每条配置读取另一个组的当前成员，筛选后追加到当前组。来源可以是这三类组，也可以是订阅暴露的内部组。

```json
{
  "type": "selector",
  "tag": "regional",
  "empty_fallback": "direct",
  "import": [
    {
      "group": "subscription-a",
      "include": ["(?i)hong kong", "香港"],
      "exclude": ["expired", "到期"],
      "types": ["shadowsocks", "trojan"],
      "match": "name"
    },
    { "group": "another-group" }
  ]
}
```

selector 和 urltest 的 `outbounds`、`import`、`empty_fallback` 至少一个非空。订阅组仍需要配置 URL，导入成员会追加到下载文档提供的成员之后；订阅的 `outbounds` 白名单仅筛选自身下载文档。

| 字段 | 含义 |
| --- | --- |
| `group` | 必填，来源组标签。订阅文档内的本地引用会自动加上命名空间。 |
| `include` | 正则表达式或表达式列表，匹配任意一条即可；省略或为空时接受所有名称。 |
| `exclude` | 正则表达式或表达式列表，匹配任意一条即排除，优先于 `include`。 |
| `types` | 协议类型或类型列表，如 `shadowsocks`、`trojan`、`selector`；省略或为空时接受所有类型。 |
| `match` | 默认 `name`：匹配去除订阅命名空间、解码 URL 转义后的原节点名。设为 `tag` 时匹配完整出站标签。 |

界面名称去除了订阅前缀，并可能添加冲突后缀；`match: "name"` 仍匹配来源文档中的原始名称，`match: "tag"` 仍匹配内部完整标签。名称展示和后缀分配不改变已有过滤结果。

表达式使用 Go 正则语法，默认区分大小写，可用 `(?i)` 忽略大小写；精确匹配可加 `^` 和 `$`。无效表达式会导致配置校验失败。名称与类型条件需同时满足；每条导入规则只筛选该条导入的成员。

成员顺序为显式节点在前，再按 `import` 配置顺序和来源成员顺序追加。相同完整标签只保留第一次出现的位置，不同订阅中原名相同的节点仍然独立。导入保留节点身份、链式代理、私有 DNS 和连接生命周期，不会重新注册一份节点。

导入读取来源组的直接有效成员列表，包括来源组通过自己的 `import` 得到的成员。如果某个成员本身是组，该成员仍保留为组，不会自动展开其子节点；需要其子节点时，另写一条指向该组的导入规则。支持任意多级导入链。

## empty_fallback

`selector`、`urltest` 和 `subscription` 均支持 `empty_fallback`，其值是同一配置文档中声明的出站、端点或组的标签。它与 `import` 同级，不是单条过滤规则的属性，不能直接引用其他订阅内部成员。

先合并静态成员（订阅自身下载文档的成员）和全部过滤后的导入成员，只有合并结果为空时才插入备用节点。成员恢复后立即移除备用节点，并按组的选择规则重新选择。仅有 `empty_fallback` 的 selector/urltest 也有效。备用成员通过 `All()`、API 和多级 `import` 可见，上游导入仍对它执行自己的过滤条件。

这只判断成员列表是否为空，不判断测速失败、拨号失败或组内节点是否可用；它不会覆盖过滤规则，也不会掩盖缺失引用、非法订阅或首次订阅下载失败。订阅仍须先成功加载有效文档或缓存。

备用引用始终参与启动顺序和完整依赖图的环检测，即使当前不会被插入。订阅内的引用按来源文档的本地声明隔离；刷新删除仍被 `empty_fallback` 引用的节点时拒绝更新。旧连接是否中断遵循组原有的 `interrupt_exist_connections` 和订阅版本保留规则。

## 刷新行为

订阅刷新后，各级导入会重新计算成员。查询和新拨号会读取当前成员，无需等待定时轮询，后台任务也会更新选择和测速。节点改名、类型变化以及同名节点更新都会重新应用筛选条件。

selector 保留仍然存在的选择。选中节点被删除时，优先使用仍在列表中的 `default`，否则选择第一个节点。`default` 使用有效成员的完整标签；订阅组也接受自身下载文档中的原节点名。带有 `import` 的 selector 将 `default` 作为选择偏好：暂时不存在时按剩余成员回退，不引入额外的成员或拨号依赖。缓存选择与默认节点会在启动时订阅加载后应用。urltest 和处于 `urltest` 模式的订阅组会对刷新后的成员测速，旧成员版本的结果不能覆盖新版本的测速记录和选择。已退役版本会停止成员监听和测速；关闭时会等待后台任务和已接受的手动测速退出。

来源为空或过滤后无匹配节点时，该条导入不提供成员。目标组最终为空时，如果配置了 `empty_fallback` 则插入指定节点，否则拨号明确报不可用，不会回退到被过滤的节点。订阅内的来源组被删除或改成普通节点后，该条导入暂时为空；恢复为组后自动恢复。首次启动时来源不存在或不是组则报配置错误。

已经成功生效的导入在消费方或父订阅热刷新时保留来源身份，来源暂时不可用不会阻止消费方更新其他节点。新增导入或改为一个尚不存在的来源仍会被拒绝。删除本地来源后，不会改为导入主配置中同名的组；缓存也会保存这一命名空间关系，重启时仍严格校验来源是否可用。恢复来源时会重新检查完整依赖图，不能利用暂时缺失的来源绕过环检测。

`selector` 和 `urltest` 的 `outbounds` 是静态引用列表，只能引用同一配置文档中声明的出站、端点或组，包括订阅组本身。不能直接填写其他订阅组内部节点或内部组的完整标签，即使它们已加载；获取这些成员应使用 `import`，需要指定节点时可用 `include` 筛选。主配置在合并配置文件后进行检查，`sing-box check` 无需下载订阅即可拒绝无效引用；订阅文档在加载时进行相同检查。订阅更新删除了仍被同一文档内的组引用的节点时，会拒绝整次更新并保留旧版本；同时修改节点声明和引用列表则可以正常更新。

订阅组自身的 `outbounds` 是下载文档的成员白名单，只能选择该文档声明的出站和端点，缺少要求的成员会拒绝更新。已有连接遵循目标组的连接中断设置和来源订阅的旧版本连接保留策略。

禁止自导入、相互导入，以及与组成员、代理链、DNS 依赖共同形成的循环。校验保守地包含来源组的依赖，即使过滤规则排除了部分成员，也不能用过滤规则绕过环检测。形成循环的订阅更新会被拒绝，旧版本继续运行。

HTTP 下载器经由使用 `import` 的组拨号时，仍遵循订阅启动引导规则：首次启动所需节点尚不可用时，应提供可用缓存或独立的 `bootstrap_http_client`。
