# 竞速 DNS

```json
{
  "type": "race",
  "tag": "private-race",
  "servers": ["private-a", "private-b"],
  "timeout": "5s"
}
```

`servers` 至少包含两个不同的 DNS 服务器标签，可以引用 DoH 或其他原生上游，也可以引用无环的竞速组；不能包含 FakeIP。`timeout` 默认沿用原生 DNS 超时，负数无效。

每次查询并发请求所有上游，每个上游使用独立请求副本。最快返回有效答案的上游获胜，其余请求取消；下次查询会重新竞速，不永久固定某个上游。对 A/AAAA 请求，成功响应必须包含对应地址记录。空答案和 NXDOMAIN 不抢占仍在等待的有效地址，只有其他请求结束或竞速超时时才回退到已有的否定答案。SERVFAIL、REFUSED、截断、网络错误及空响应不作为成功结果；全部失败返回错误。调用取消或内核关闭也会取消竞速。

可直接用于 `domain_resolver: "private-race"` 或 DNS 路由。它选择最快的 DNS **解析结果**供后续拨号使用，不测量返回 IP 的 TCP 速度；地址间的拨号行为继续遵循原生拨号器。缓存命中时不重新发送查询，遵循调用方 DNS 缓存配置；需每次竞速可在节点解析器中设置 `disable_cache`。

竞速组及其上游的解析器、出站拨号关系参与统一环路校验。组不拥有上游生命周期，关闭、重置和资源回收仍由所在作用域管理。
